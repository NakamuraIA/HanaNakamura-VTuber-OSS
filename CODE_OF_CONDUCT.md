# Código de Conduta

Queremos uma comunidade respeitosa e segura para todas as pessoas.

## Comportamento esperado

- conversar com respeito, mesmo durante discordâncias;
- criticar ideias e código, não pessoas;
- aceitar correções e explicar decisões com clareza;
- proteger dados pessoais, credenciais e conteúdo privado;
- ajudar pessoas com diferentes níveis de experiência e acessibilidade.

## Comportamento inaceitável

- assédio, ameaça, discriminação ou ataque pessoal;
- divulgação de dados privados ou credenciais;
- spam, fraude, impersonação ou conteúdo deliberadamente enganoso;
- pressão para que alguém execute código ou compartilhe dados sem entender o
  risco;
- interrupção repetida e intencional das discussões do projeto.

## Aplicação

A manutenção pode editar ou remover conteúdo, encerrar discussões e limitar a
participação de quem violar estas regras. A decisão deve considerar o contexto,
a gravidade e a repetição do comportamento.

Para relatar uma situação de forma privada, contate a manutenção pelo perfil
GitHub `NakamuraIA`. Não publique dados pessoais no relato público.

Este código vale no repositório e nos espaços oficiais ligados ao projeto.
