# Suporte

## Antes de pedir ajuda

1. Leia [README.md](README.md) e [FIRST_RUN.md](FIRST_RUN.md).
2. Procure o erro nas issues (registros de problema) existentes.
3. Reinicie backend e frontend e confirme qual parte falhou.

## Onde pedir

- bug reproduzível: use o formulário **Relatar um bug**;
- sugestão: use o formulário **Sugerir uma melhoria**;
- vulnerabilidade: siga [SECURITY.md](SECURITY.md), sem abrir detalhes públicos.

Informe sistema operacional, versão, provider usado e passos para reproduzir.
Pode anexar registros curtos, mas remova chaves, tokens, caminhos pessoais,
conversas privadas e conteúdo do banco.

O projeto não garante prazo de resposta nem oferece suporte para cobrança,
contas ou indisponibilidade dos providers externos.
